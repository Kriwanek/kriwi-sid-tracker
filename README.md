# kriwi-sid-tracker

Ziel: eine freie Toolchain vorbereiten, um SID-ähnliche Tracks zu erstellen und sie später in eine DAW wie FL Studio zu mischen.

## Freie Versionen von GitHub

* **GoatTracker 2 (GPL-2.0)** ist als Open-Source-Projekt auf GitHub verfügbar.
  * Repo: <https://github.com/leafo/goattracker2>

## Setup (Download der freien Tools)

```bash
./scripts/fetch_free_tools.sh
```

Das Skript klont (oder aktualisiert) GoatTracker 2 nach `vendor/goattracker2`.

## Hinweis zu FL Studio

FL Studio ist proprietär und wird nicht frei auf GitHub angeboten. Für Tests nutze die offizielle Demo/Trial-Version vom Hersteller.
