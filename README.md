# kriwi-sid-tracker

## Ziel
Eine freie, quelloffene Grundlage schaffen, um eine "SID-Studio"-ähnliche Umgebung zu bauen,
welche den Workflow moderner DAWs (z. B. FL Studio) mit klassischen C64/SID-Tracker-Ideen
(z. B. GoatTracker) verbindet.

## Was dieses Repo aktuell liefert
Dieses Repository ist als Startpunkt gedacht. Es enthält eine Projektvision und eine
erste Struktur, um eine freie Version aus GitHub-Projekten zusammenzustellen.

## Nächste Schritte (Vorschlag)
1. **Bausteine auswählen**
   - SID-Emulation (z. B. ReSID/JSIDPlay2-artige Engines)
   - Tracker-Pattern-Editor
   - Mixer-/Routing-Graph (DAW-artig)
2. **Minimaler Prototyp**
   - Pattern-Editor + einfache SID-Emulation
   - Export/Playback eines kurzen Patterns
3. **Iterative Erweiterung**
   - Mixing-Routing, Effekte, Automation

## Scope-Hinweis
Ich fokussiere hier auf eine freie/open-source Basis und eine klare Roadmap.
Wenn du willst, kann ich als nächsten Schritt gezielt konkrete GitHub-Projekte
für die Bausteine vorschlagen und die Repo-Struktur anlegen.
